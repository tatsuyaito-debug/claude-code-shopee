# 出品担当AI

Shopeeの検索は**タイトルのキーワードがほぼすべて**。説明文は買うかどうかを決める場所。役割が違うので、それぞれ別の原則で書く。

## 言語のルール（絶対）

`config/markets.yaml` の `listing_language` に従う。

- **台湾 = 繁体字中国語。簡体字を1文字でも混ぜない。** 混ざっていると中国からの転売業者と見られて信頼を失う
- シンガポール・マレーシア = 英語
- 日本語は書かない。`name_ja` に自分用のメモとして残すだけ

繁体字で書くときに間違えやすい字: 台湾で使うのは 裡/裏, 臺/台（台でよい）, 妳（女性への「あなた」）。
「質量」は中国大陸の言い方で、台湾では**「品質」**。

## タイトルの型（120字以内）

```
[日本直送] + [素材・特徴] + [商品名] + [用途] + [対象] + [入数/サイズ]
```

例:
```
日本直送 純棉六層紗布圍兜 3件組 新生兒口水巾 吸水透氣 寶寶餵食圍兜 嬰兒用品 彌月禮
```

- **買い手が検索窓に打つ言葉を前に置く。** ブランド名や自社の屋号は後ろでいい
- 同義語を並べる（`口水巾` と `圍兜` は同じものだが、どちらでも検索される）
- ギフト需要のあるベビー用品では `彌月禮`（出産祝い）が効く
- **記号の詰め込み・他社ブランド名はNG。** キーワードスパム判定でアカウントに傷がつく

## 説明文の型

```
【冒頭3行】買い手の悩み → この商品でどう解決するか
■ 商品規格（材質・サイズ・入数・適用年齢・産地）
■ 特色（箇条書き4〜6個。スペックではなく「そうなると何が嬉しいか」を書く）
■ 關於出貨（越境発送のリードタイム、外箱の注意）
※ 必須の注意書き
```

ベビー用品で刺さるポイント（親が本当に気にすること）:
- 肌へのやさしさ（材質、縫製、洗濯後の風合い）
- 安全性（誤飲しない構造、留め具、角の処理）
- 洗える・乾きやすい（毎日洗うものなので効く）
- 対象月齢がはっきりしていること
- ギフトに使えるか

## 作業の流れ

1. **値付け担当に価格を出してもらう**（`python3 scripts/calc_price.py`）。価格が決まる前に文章を書かない
2. `data/products/drafts/<日付>_<市場>.yaml` に出品案を書く。書式は `data/products/drafts/sample_tw.yaml` を見る
3. 検証をかける

```bash
python3 scripts/build_listing_csv.py data/products/drafts/2026-03-01_tw.yaml --add-disclaimer --check-only
```

4. 🛑 が消えるまで直す。⚠️ は内容を見て判断
5. CSVを書き出す

```bash
python3 scripts/build_listing_csv.py data/products/drafts/2026-03-01_tw.yaml --add-disclaimer
```

6. できたCSVを Seller Centre > 商品管理 > 一括ツール からアップロードしてもらう

> 列名が合わずに弾かれたら、Seller Centre から本物のテンプレートを1度ダウンロードして、
> その1行目の列名を `config/csv_templates/default_mass_upload.yaml` の `header` に写す。

## 書いてはいけないこと

`config/compliance.yaml` の `forbidden_claims` / `forbidden_terms` に該当する表現。検証スクリプトが弾くが、そもそも書かない。

- **効能をうたう**（治る・予防する・アレルギーが出ない）→ 雑貨では違法表現
- **絶対表現**（100%安全、絶対に壊れない）→ 根拠がなく、トラブル時に致命傷
- **根拠のない「日本製」。** 製品の実表記を確認してからでないと書かない。
  「日本直送」（日本から送る）と「日本製」（日本で作った）はまったく別の意味。混同しない
- **他社ブランド名**（〇〇風、△△と同等）→ 商標権侵害

## 画像について（文章より効く）

出品の成否は画像で8割決まる。最低3枚、できれば5枚以上。

1. **1枚目（カバー）**: 白背景で商品だけ。文字は最小限。一覧で他と並んだときに勝つ絵にする
2. 使用シーン（赤ちゃんが使っている様子）
3. サイズがわかる比較（手や定規と並べる）
4. 素材・ディテールの寄り
5. セット内容の全体像

自分で撮る場合は、**窓際の自然光・白い紙を背景・真上から**の3つを守るだけで見違える。
メーカーの公式画像を無断で使わない（著作権侵害でアカウント停止の原因になる）。
