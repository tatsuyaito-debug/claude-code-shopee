# Shopee ベビーグッズ AI社員

奥さんが Shopee（台湾・東南アジアのECモール）で日本のベビーグッズを売るための、
**7人のAI社員チーム**とその道具一式。

Claude Code に日本語で話しかけるだけで、商品選定・値付け・出品文作成・顧客対応・
発送管理・数字の分析まで、一通りの店舗運営が回るようにしてあります。

```
「今日なにをやればいい？」          → 店長AI が1日の作業を3つに絞って出す
「この商品、仕入れて大丈夫？」        → リサーチAI が規制と利益を確認して可否を出す
「いくらで売ればいい？」            → 値付けAI が送料・手数料・為替込みで計算する
「台湾向けの出品文を書いて」         → 出品AI が繁体字で書いてCSVまで作る
「このお客さんにどう返信する？」       → CS AI が繁体字の返信文＋日本語訳を出す
「今週どうだった？」               → 数字AI が利益ベースで振り返って次の手を出す
```

## AI社員の紹介

| 社員 | 担当 | こんなときに |
|---|---|---|
| 🧑‍💼 **店長** | 全体の仕切り | 「今日なにする？」「週次のふりかえりして」 |
| 🔍 **リサーチ** | 商品選定 | 「何を仕入れる？」「これ出品していい？」 |
| 💰 **値付け** | 価格決定 | 「いくらで売る？」「競合が安いけど下げていい？」 |
| ✍️ **出品** | 商品ページ作成 | 「出品文を書いて」「CSVを作って」 |
| 💬 **顧客対応** | チャット・レビュー | 「この問い合わせにどう返す？」「クレームが来た」 |
| 📦 **受注・発送** | 出荷と在庫 | 「今日の発送分は？」「何を補充する？」 |
| 📊 **数字** | 集計と分析 | 「今月どうだった？」「どれが儲かってる？」 |

社員の中身は `.claude/skills/` にあります。あとから増やすことも、書き換えることもできます。

## はじめかた

**セットアップ手順は [`docs/はじめかた.md`](docs/はじめかた.md) を見てください。**
やることは3つだけです。

1. `config/business.yaml` に目標と利益方針を書く
2. `config/markets.yaml` の為替・手数料・送料を実際の数字に直す（★ここが一番大事）
3. `data/products/products.csv` に扱う商品の原価と重量を入れる

そのあとは、Claude Code を開いて話しかけるだけです。

## 道具（AIが裏で使うスクリプト）

```bash
# この商品、いくらで売れば儲かる？
python3 scripts/calc_price.py --cost 1200 --weight 150 --size 20x15x4

# 競合の450元に合わせたら利益は？
python3 scripts/calc_price.py --sku BIB-001 --competitor 450

# 出品案をチェックしてCSVにする
python3 scripts/build_listing_csv.py data/products/drafts/sample_tw.yaml --add-disclaimer

# 今週の成績
python3 scripts/weekly_report.py --days 7
```

手で叩く必要はありません。AIが必要なときに実行します。

## この仕組みが守っていること

- **赤字出品を止める** — 送料・手数料・為替・広告費・返品ロスまで入れて計算し、
  損益分岐点を下回る価格を提案しません
- **法令・規約違反を止める** — ベビー用品の禁止カテゴリ（粉ミルク、チャイルドシート等）と、
  効能をうたう禁止表現を機械的にチェックします
- **作業を増やしすぎない** — 1日の作業時間を設定に持ち、その範囲に収まる提案しかしません

## 前提と注意

- 販売形態は **日本で仕入れ → Shopee国際物流(SLS)で越境発送** を想定
- 主戦場は **台湾**。設定を足せばシンガポール・マレーシアにも横展開できます
- Shopee連携は **CSV運用**（API審査不要ですぐ使える）。将来のAPI連携用の土台も用意済み
- ⚠️ `config/markets.yaml` の手数料率・送料・為替は**仮の数字**です。
  実際の Seller Centre の値に置き換えるまで、計算結果は目安として扱ってください
