# 商品画像の置き場

SKUごとのフォルダに入れてください。

```
data/products/images/
  BIB-001/
    01-cover.jpg      ← 1枚目。白背景で商品だけ。一覧に出る絵
    02-scene.jpg      ← 使用シーン
    03-size.jpg       ← サイズ比較（手や定規と並べる）
    04-detail.jpg     ← 素材・ディテールの寄り
    05-set.jpg        ← セット内容の全体像
```

**ファイル名の先頭に 01, 02 と番号を振ってください。** その順番がそのまま出品の並び順になります。

## 撮り方（3つ守れば十分）

1. **窓際の自然光**で撮る（蛍光灯は色が濁ります）
2. **白い紙を背景**に敷く（画用紙でもコピー用紙でも可）
3. **真上から**撮る

## サイズの目安

- **正方形**（1:1）にする。一覧表示で上下が切れるのを防ぎます
- 1辺 **1000px以上**が望ましい（最低500px）
- 1枚 **2MB以下**

`python3 scripts/build_listing_csv.py <出品案>` を流すと、サイズや正方形かを自動でチェックして、
アップロード手順書を書き出します。

## 注意

**メーカーの公式画像を無断で使わないでください。** 著作権侵害でアカウント停止の原因になります。
自分で撮った写真を使ってください。
