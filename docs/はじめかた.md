# はじめかた

パソコンの操作に自信がなくても大丈夫です。**やることは「設定ファイルに数字を書く」だけ**で、
あとはClaude Codeに日本語で話しかけて使います。

---

## ステップ0: 準備するもの

| 必要なもの | 備考 |
|---|---|
| Shopeeの出店アカウント | 日本からの越境出店（Shopee Japan の越境セラー登録） |
| Claude Code | このリポジトリを開いて話しかける窓口 |
| Python 3.11 以上 | 計算スクリプトを動かすのに使う |

```bash
pip install -r requirements.txt
```

---

## ステップ1: お店の方針を決める（`config/business.yaml`）

ここに書いた数字が、AI社員の判断基準になります。**最初は控えめでいい**ので、必ず自分の数字を入れてください。

```yaml
goals:
  monthly_revenue_jpy: 300000   # 月の売上目標
  monthly_profit_jpy: 90000     # 月の利益目標（ここが本命）
  daily_work_minutes: 60        # 1日に使える作業時間

pricing:
  target_margin_rate: 0.25      # 目標利益率25%
  min_margin_rate: 0.12         # 12%を切る商品は出品しない
  min_profit_jpy: 300           # 1個あたり300円未満は扱わない
```

> 💡 **`min_profit_jpy` は大事です。** 利益率が良くても1個50円では、梱包と発送の手間に見合いません。
> 「1個いくら残れば、この作業をやる価値があるか」で決めてください。

## ステップ2: 販売先の数字を入れる（`config/markets.yaml`）★最重要

**ここが仮の数字のままだと、すべての計算が嘘になります。** 出品を始める前に必ず直してください。

直すのは4つです。

### ① 為替レート

```yaml
fx:
  jpy_per_unit: 4.80        # 1台湾ドル = 何円か
  updated_at: 2026-09-21    # 調べた日
```
「台湾ドル 円」で検索すれば出ます。**月に1回は更新してください。**
古くなると、AI社員が「レートが古いので数字を信じないで」と警告を出します。

### ② Shopeeの手数料率

Seller Centre の「マイ収益」や手数料の案内ページで、自分のアカウントの実際の率を確認します。

```yaml
fees:
  commission_rate: 0.06       # 販売手数料
  transaction_fee_rate: 0.02  # 決済手数料
  service_fee_rate: 0.00      # 無料配送プログラム等に入っている場合
```

### ③ 国際送料（SLS）

SLSの料金表を見て、基本料と1kgあたりの単価を入れます。

```yaml
shipping:
  base_jpy: 180.0     # 1個あたりの基本料
  per_kg_jpy: 950.0   # 1kgあたり
```

### ④ 使わない市場は消してよい

まずは台湾だけで始めるなら、`SG:` と `MY:` のブロックは残しておいても害はありません
（`business.yaml` の `secondary_markets` から外せば、普段は使われません）。

## ステップ3: 商品を登録する（`data/products/products.csv`）

Excelでも編集できます（保存するときは「CSV UTF-8」を選んでください）。

| 列 | 意味 | 注意 |
|---|---|---|
| `sku` | 自分で決める商品コード | 例: `BIB-001`。あとで変えない |
| `name_ja` | 日本語の商品名 | 自分がわかればOK |
| `cost_jpy` | 仕入れ値（税込） | **送料込みの実際に払った額** |
| `weight_g` | **梱包した状態の**重さ | 商品だけでなく袋や緩衝材込み |
| `length_cm` `width_cm` `height_cm` | 梱包後の外寸 | 大きいと送料が上がるので正確に |
| `points_back_rate` | ポイント還元率 | 10%還元なら `0.10` |
| `stock` | 手持ちの在庫数 | |

> 💡 **重量は必ずキッチンスケールで実測してください。** 越境販売では送料が利益を左右するので、
> ここが適当だと「儲かるはずが赤字だった」が起きます。

## ステップ3.5: 誰が発送するか決める（`config/fulfillment.yaml`）

自分で梱包するなら、何もしなくて大丈夫です（既定は `active: self`）。

**ShopeeKing などの発送代行に任せる場合**は、代行料金を入れて `active` を切り替えます。
手順は [`発送代行の使い方.md`](発送代行の使い方.md) を見てください。

## つまずきやすいところ

| 症状 | 原因と対処 |
|---|---|
| `商品マスタが見つかりません` | `data/products/products.csv` が無い。ステップ3を実施 |
| `市場コード 'XX' は config/markets.yaml にありません` | `business.yaml` の `primary_market` のつづりを確認 |
| 注文CSVを読めない | `config/csv_templates/order_export.yaml` の `aliases` に、自分のCSVの列名を追記する |
| 出品CSVがShopeeに弾かれる | Seller Centreから本物のテンプレを落として、列名を `config/csv_templates/default_mass_upload.yaml` に写す |
| `ModuleNotFoundError: yaml` | `pip install -r requirements.txt` を実行 |
| 発送代行の料金が未入力と言われる | `config/fulfillment.yaml` の `providers.shopeeking` に契約の実数を入れる |
| 為替が古いと言われる | `config/markets.yaml` の `fx` を更新し、`updated_at` も今日の日付に直す |
