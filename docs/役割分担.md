# 役割分担：奥さん・夫・AI

このお店は3者で回します。**誰が何を持つかを決めておかないと、二重管理になるか、
逆に誰も見ていない穴ができます。**

---

## 一行でいうと

> **奥さんが「見て・決める」、夫が「整備する」、AIが「計算する」。**

---

## 奥さん（運転手）— 日々の運用を持つ

| 持つもの | 頻度 |
|---|---|
| 注文の確認と発送 | 毎日 |
| チャット返信 | 毎日 |
| 商品を見る目（リサーチ） | 週 |
| 出品する/しないの最終判断 | 都度 |
| 顧客対応の文面の最終確認 | 都度 |

**特に「商品を見る目」は、代わりがききません。**
Shopeeの商品ページを自分で見て「これは売れる/売れない」の感覚を作るのは、
立ち上げ期に一番価値のある投資です。これがないと、AIの判定を鵜呑みにするしかなくなり、
AIが間違ったときに気づけません。

最初の30商品だけは、必ず自分の目で見てください。

---

## 夫（整備士）— 仕組みと数字を持つ

**日々の運用には入りません。** 入ると二重管理になって、かえって遅くなります。
持つのは次の3つだけです。

### 1. 設定ファイルの管理（月10分）

```bash
python3 scripts/check_setup.py
```

- 為替レートの更新（月1回）
- Shopee手数料・SLS送料が変わっていないか
- `verified: true` への書き換え
- 発送代行の料金改定

**ここが止まると、利益計算が全部ずれます。** 月1回だけ見てください。

### 2. お金の判断（都度・2人で）

- 初期投資（最初のテスト仕入れ 約2万円）
- 赤字SKUからの撤退
- 発送代行への切り替え（月1万円以上の固定費が増える）
- 仕入れ規模を上げるかどうか

**家計に関わる判断は2人で決める。** AIは材料を出しますが、決めるのは人間です。

### 3. 詰まったときの修理（都度）

- スクリプトがエラーで止まった
- CSVの列が合わずにShopeeに弾かれた
- 新しい機能を足したい

奥さんが非エンジニアなら、ここは夫にしか直せません。

---

## AI社員 — 計算と照合を持つ

| 得意 | なぜ |
|---|---|
| 規制チェック | 14カテゴリを毎回照合するのは人間には無理。見落としがアカウント停止になる |
| 利益計算 | 送料・手数料・為替・容積重量。暗算できる人はいません |
| 仕入れ上限の逆算 | 同上 |
| 繁体字の出品文・返信文 | 書けるとしても時間が違いすぎます |
| 週次の集計 | 手作業でやる価値がゼロ |

**AIがやらないこと：** 現物を見ること、現地（台湾Shopee・仕入れ先）を見ること、
お金と顧客への約束を確定すること。

### 確認済みの事実

この環境から次のサイトには接続できません（2026-10-17 時点で確認）。

```
shopee.tw                接続不可
www.nishimatsuya.com     接続不可
netsea.jp                接続不可
```

Web検索は使えますが、返ってくるのはブログ記事の要約です。
**Sold数・現在の価格帯・上位出品の画像**といった生きたデータは含まれません。

### 覚えておく一行

> **AIが「見てきた」情報を根拠に話し始めたら、疑ってください。**

AIが見られるのは、このリポジトリの中のファイルと、あなたが貼った情報だけです。
それ以外を根拠にした「売れています」「相場はこのくらいです」は、
古い記事からの推測か、作り話です。

**データがないときは「未確認」と言うのが正しい動作**です。そう言わせてください。

## 一緒にやること：週次のふりかえり（30分）

決めた曜日に、2人で。

```bash
python3 scripts/weekly_report.py --days 7
```

AIがレポートと打ち手を3つ出すので、それを見ながら話します。
**ここだけは夫も入ってください。** 数字の流れを2人が共有していないと、
お金の判断（上の2）ができなくなります。

## やってはいけない分担

| ダメなパターン | なぜ |
|---|---|
| 夫がリサーチを代行する | 奥さんの目が養われず、後で全部の判断が止まる |
| 夫が日々の発送・CSに口を出す | 二重管理。遅くなるだけ |
| 奥さんが設定ファイルを触る | 壊すと全部の計算がずれる。夫が持つほうが安全 |
| 夫が完全に手を引く | 月1回の設定更新で止まり、数字が嘘になる |
