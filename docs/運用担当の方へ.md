# はじめての方へ

このページは、**お店を実際に動かす人**のためのものです。
プログラミングの知識は要りません。やることは「日本語で話しかける」だけです。

---

## これは何か

Shopee（台湾のネットショップ）で、日本のベビーグッズを売るためのお店の仕組みです。

**7人のAI社員**がいて、それぞれ担当が違います。困ったら誰に聞けばいいか分からなくても大丈夫で、
とりあえず話しかければ、適切な担当に回されます。

---

## いまは準備不要です（夫が窓口のあいだ）

売上が立つまでは、**夫が窓口**になります。奥さん専用のアカウントは作りません。
下の「準備」は、**注文が月20件を超えてから**で大丈夫です。

それまでは、こう動きます。

| 奥さんが単独でやる | 夫に聞く |
|---|---|
| 注文確認・発送（Shopeeアプリ） | 返金・返品・値下げの判断 |
| よくある問い合わせの返信（定型文） | 仕入れの可否 |
| 台湾Shopeeを見る（リサーチ） | 価格を決めるとき |

**質問は1日分ためて、まとめて夫に渡してください。** 都度だと夫が疲れて、かえって遅くなります。
急ぐのは発送期限だけです。

下の「場面別・そのまま使える言い方」は、**夫に伝える言葉としてそのまま使えます。**

## 準備（1回だけ・20分）※ 切り替えるときに読む

必要なアカウントは2つです。

| | 費用 |
|---|---|
| GitHub アカウント | 無料 |
| Claude アカウント | **有料プランが必要**（Pro / Max / Team のいずれか） |

> ⚠️ **Claude Code は無料プランでは使えません。** 金額は
> [claude.ai](https://claude.ai) のプランページで確認してください。

### 1. GitHubのアカウントを作る（5分・無料）

[github.com/signup](https://github.com/signup) を開きます。

1. メールアドレスを入れる
2. パスワードを決める
3. **ユーザー名**を決める（半角英数字。あとで使うので控えておく）
4. メールに届いた認証コードを入れる
5. プランを聞かれたら **Free** を選ぶ

できたら、**ユーザー名を夫に伝えてください。**

### 2. 招待を受ける（1分）

夫がリポジトリに招待すると、メールが届きます。リンクを開いて **Accept invitation** を押します。

### 3. Claudeのアカウントを作る（5分）

[claude.ai](https://claude.ai) でサインアップし、**Pro以上のプラン**に加入します。

### 4. Claude Code を開く（5分）

[claude.ai/code](https://claude.ai/code) を開きます。

1. GitHubとの連携を求められるので、許可する
2. リポジトリの一覧から `claude-code-shopee` を選ぶ
3. 出てきたら成功です

スマホの Claude アプリの **Code タブ**からも同じことができます。

## 毎日やること

朝いちばんに、これだけ聞いてください。

> **今日なにをやればいい？**

やることを**3つまで**に絞って出してくれます。所要時間も付いてくるので、
時間がない日は一番上の1つだけで大丈夫です。

## 場面別・そのまま使える言い方

コピーして貼り付けて構いません。

### 注文があったとき

```
今日の発送分は？
```

発送のチェックリストが出ます。梱包の仕方、剥がし忘れがないかまで出ます。

### お客さんから連絡が来たとき

お客さんの文章をそのまま貼り付けて、

```
このお客さんにどう返信する？
```

**繁体字の返信文と、その日本語訳**が出ます。日本語訳を読んで納得してから送ってください。

> ⚠️ **返金・返品・値引きの約束だけは、自分で決めてください。** AIに決めさせないこと。

### 商品を仕入れようか迷ったとき

```
この商品、仕入れて大丈夫？
西松屋で1200円、150g、20x15x4cmくらい、日本製のガーゼスタイ3枚組
```

法律やShopeeのルールに引っかからないか、送料と手数料を引いて利益が残るかを計算して、
**仕入れていいかどうか**を答えます。

### 台湾での売値を見たとき

```
台湾で699元で売られてる。200gくらい。仕入れいくらまでなら勝負できる？
```

**「1,152円以下で仕入れられるなら戦えます」**のように答えます。
その金額を持って、お店の値札と比べてください。

### 出品するとき

```
BIB-001 の台湾向け出品文を書いて
```

繁体字のタイトルと説明文、アップロード用のファイルまで作ります。

### 1週間終わったとき

```
今週のふりかえりをして
```

売上ではなく**利益**で振り返って、来週やることを3つ出します。
**これは夫と一緒に見てください。**

## 困ったとき

### 何を聞けばいいか分からない

```
今の状況を教えて
```

とりあえずこれで大丈夫です。

### AIの言っていることがおかしい気がする

**その直感は正しいことが多いです。** そのまま言ってください。

```
それ本当？根拠は？
```

AIが見られるのは、この仕組みの中にあるファイルと、あなたが貼った情報だけです。
**台湾のShopeeや、西松屋のサイトは見られません。**
それなのに「売れています」「相場はこのくらいです」と言い出したら、それは推測です。

### エラーが出た・動かない

**夫に言ってください。** ここは直せる人が限られます。
無理に触らず、画面をそのまま見せるのが一番早いです。

---

## 触らないほうがいいもの

| | なぜ |
|---|---|
| `config/` の中のファイル | 壊すと利益計算が全部ずれます。夫が管理します |
| 損益分岐点を下回る値下げ | 売るほど損をします |
| 返金・返品の約束をAIに任せる | お金の約束は人間が決めること |

---

## いちばん大事なこと

**最初の30商品は、自分の目で見てください。**

台湾のShopeeを開いて、売れている商品を眺める時間です。これをやっておくと、
「この商品は売れそう」「これは埋もれる」という感覚ができます。

その感覚がないままだと、**AIが間違ったときに気づけません。**
AIは計算は得意ですが、商品を見る目はありません。そこはあなたにしかできない仕事です。
