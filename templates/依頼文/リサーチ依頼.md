# リサーチ依頼の文面（LINEで送る用）

実務担当に台湾Shopeeを見てきてもらうときの依頼文。
**2通に分けて送る**と、キーワードがコピペしやすい。

カテゴリを変えて何度も使うので、キーワードの部分だけ差し替えて使い回す。

---

## 1通目：依頼本文

```
台湾のShopeeで、どんなベビー用品が売れてるか見てきてほしい📱

【やること】30〜60分
スマホのブラウザで shopee.tw を開く
※ログイン不要。買い手として見るだけ
次に送るキーワードをコピペして検索

【見るのは3つだけ】
① 売れた数（「已售出 ◯◯」みたいに出てる数字）
② 上位5件くらいの値段
③ 写真や説明がイマイチな店（←ここが狙い目）

【メモしてほしいこと】
商品名 / 値段 / 売れた数　の3つだけ
例）ガーゼスタイ3枚組 / 399元 / 1200件

5〜10個くらい集まればOK。
スクショ送ってくれるだけでも大丈夫👌

【注意】
まだ何も買わなくていい！見るだけ。
値段は「元」のままでOK。計算はこっちでやる。

【なんでやるの】
ここで「売れる商品の感じ」がつかめると、
このあとの商品選びが全部ラクになる。
一番大事なとこだけお願いしたい🙏
```

## 2通目：検索キーワード（コピペ用）

```
検索はこれをコピペして👇

日本 嬰兒用品

日本 口水巾

日本 紗布毛巾

日本 尿布收納包

新生兒 彌月禮
```

---

## キーワードの意味（送る側の参考）

| 繁体字 | 意味 | なぜこれか |
|---|---|---|
| 日本 嬰兒用品 | 日本のベビー用品 | 全体の相場をつかむ |
| 日本 口水巾 | スタイ・よだれかけ | 軽い・薄い・規制が少ない |
| 日本 紗布毛巾 | ガーゼタオル | 同上。日本製の評価が高い |
| 日本 尿布收納包 | おむつポーチ | 単価が取れて軽い |
| 新生兒 彌月禮 | 出産祝い | 台湾は満1ヶ月を祝う習慣があり、ギフト需要が強い |

**布製品と雑貨に寄せてあります。** 圧縮して薄く送れて国際送料が安く、
規制にも当たりにくいため。歯固め・ベビー食器・スキンケアは要確認カテゴリなので、
最初のリサーチからは外しています。
