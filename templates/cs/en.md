# Chat reply templates (Singapore / Malaysia — English)

CS担当AIがこれをベースに個別事情を足して使う。`{}` は必ず差し替える。

---

## 1. Order confirmation (before shipping)

```
Hi, thank you for your order! 😊
All items in our shop are shipped directly from Japan. We will dispatch your parcel within {2} working days and share the tracking number once it is on its way.
Feel free to message us anytime if you have questions!
```

## 2. Shipping notice

```
Hi, your order has been shipped!
Tracking number: {tracking}
It is sent from Japan and usually arrives in 7-14 working days (excluding holidays and customs clearance).
Please contact us first if anything is wrong when it arrives — we will sort it out for you 🙏
```

## 3. "Where is my parcel?" (within normal time)

```
Hi, thanks for checking in. Here is the latest tracking status:
{status}
As the parcel ships directly from Japan, international transit and customs clearance normally take 7-14 working days, so your order is still within the expected window.
If it has not arrived by {date}, please let us know and we will chase it up immediately 🙏
```

## 4. "Where is my parcel?" (overdue)

```
Hi, we are very sorry for the delay.
We have raised an enquiry with the courier and will get back to you with an update within {3} working days.
If the parcel is confirmed lost, we will issue a full refund or send a replacement — whichever you prefer.
Thank you for your patience 🙏
```

## 5. Stock enquiry

**In stock**
```
Hi, this item is in stock. We will ship within {2} working days after your order 😊
```
**Out of stock**
```
Hi, this item is currently out of stock and we expect to restock around {date}.
We will update the listing once it is back — happy to notify you directly if you'd like 🙏
```

## 6. Product specification

```
Hi, here are the details for this item:
- Material: {material}
- Size: {size}
- Suitable age: {age}
- Made in: {origin}
{answer to their question}
Let us know if there is anything else you'd like to check 😊
```

## 7. Dented outer packaging

```
Hi, thanks for letting us know.
This item ships directly from Japan, and the outer packaging can pick up minor dents during international transit — this is noted on the product page. The product itself is unaffected.
If the item itself is damaged, please send us a photo and we will take care of it right away 🙏
```

## 8. Damaged / faulty item (our fault)

```
Hi, we are very sorry for the trouble.
We have confirmed the issue and will resolve it immediately. Would you prefer:
1) a full refund, or
2) a replacement sent to you
You do not need to return the item either way. Please let us know which you prefer 🙏
```
> ※ **Get the owner's confirmation before sending this.**

## 9. Return request

```
Hi, we understand.
As the item was shipped from Japan, international return postage usually costs more than the item itself. We would therefore suggest:
- a partial refund of {amount}, with no need to return the item
If you would still prefer a full return, we will process it through Shopee's standard return flow. Just let us know 🙏
```

## 10. Discount request

```
Hi, thank you for asking!
Our current price is already the best we can offer — the item is shipped directly from Japan and we absorb part of the shipping cost, so there is little room to adjust 🙏
We do release vouchers from time to time, so do follow our shop!
```

## 11. Customs / import tax

```
Hi, regarding import duties:
Taxes depend on your country's customs rules and the declared value, and whether duty applies is decided by customs. Any charges would be payable by the recipient. Thank you for understanding 🙏
```

## 12. Review replies

**5★**: `Thank you so much for your kind review! So glad your little one likes it 😊`

**3-4★**: `Thank you for the feedback! We're glad you liked {good point}. We have improved {issue} by {action} — thanks for letting us know 🙏`

**1-2★**: `We're very sorry about your experience. Regarding {issue}, we have {action taken} and changed {prevention}. Please reach out to us anytime if we can help 🙏`
