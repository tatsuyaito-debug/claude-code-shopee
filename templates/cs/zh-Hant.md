# チャット返信テンプレート（台湾・繁体字）

CS担当AIがこれをベースに、個別の事情を足して使う。
`{}` の中は必ず実際の情報に差し替えること。**そのまま送らない。**

---

## 1. 注文のお礼（発送前）

```
您好，感謝您的訂購！😊
本賣場商品皆由日本直接寄出，我們會在 {2} 個工作天內完成出貨。
出貨後會提供追蹤編號，請您耐心等候。
如有任何問題歡迎隨時詢問！
```
> 訳: ご注文ありがとうございます。日本から直送で、2営業日以内に発送します。発送後に追跡番号をお知らせします。

---

## 2. 発送のお知らせ

```
您好，您的訂單已經出貨了！
追蹤編號：{追跡番号}
由日本寄出，預計 7〜14 個工作天送達（不含例假日與清關時間）。
收到商品後如有任何問題，請先與我們聯繫，我們會盡快為您處理 🙏
```
> 訳: 発送しました。追跡番号は〜。日本発なので7〜14営業日程度かかります。

---

## 3. 「まだ届かない」（標準日数内）

```
您好，讓您久等了，我們查詢了物流狀態：
目前狀態：{現在の追跡ステータス}
由於是從日本直送，需經過國際運送與清關，一般需要 7〜14 個工作天。
您的訂單目前在正常的運送範圍內，請再耐心等候幾天。
若超過 {期限} 仍未收到，請再告訴我們，我們會立即為您查詢 🙏
```
> 訳: 追跡状況は〜です。日本直送のため通常7〜14営業日かかります。標準の範囲内なのでもう少しお待ちください。期限を過ぎたらご連絡ください。
>
> ※ 謝りすぎない。標準日数内なら「遅れている」と認めない。事実で安心させる。

---

## 4. 「まだ届かない」（標準日数を超過）

```
您好，非常抱歉讓您久等了。
我們已向物流方提出查詢，會在 {3} 個工作天內回覆您查詢結果。
若確認包裹遺失，我們將為您全額退款或重新寄出，由您選擇。
造成不便非常抱歉，感謝您的耐心 🙏
```
> 訳: 大変お待たせして申し訳ありません。物流に照会中で、3営業日以内に結果をお伝えします。紛失が確認できた場合は全額返金か再送をお選びいただけます。
>
> ※ 期限を切って約束する。約束した日に必ず再連絡する。

---

## 5. 在庫の問い合わせ

**在庫あり**
```
您好，這款目前有現貨，下單後我們會在 {2} 個工作天內出貨 😊
```

**在庫なし**
```
您好，這款目前缺貨中，預計 {日付} 左右補貨。
補貨後我們會更新賣場，也可以先幫您留意，補到貨再通知您 🙏
```
> ※ 無いものを「ある」と言わない。これが一番トラブルになる。

---

## 6. 商品仕様の質問

```
您好，關於這款商品：
・材質：{素材}
・尺寸：{サイズ}
・適用年齡：{対象月齢}
・產地：{原産国}
{質問への具体的な回答}
如果還有其他想確認的地方，歡迎隨時詢問 😊
```
> ※ わからないことは「確認してご連絡します」と言う。推測で答えない。

---

## 7. 外箱のへこみ・傷

```
您好，收到您的訊息了。
本商品由日本直送，外包裝在國際運送過程中偶爾會有輕微壓痕，
這部分在商品頁面也有註明，商品本身的品質不受影響。
如果商品本身有損壞，請拍照給我們，我們會立即為您處理 🙏
```
> 訳: 外箱のへこみは越境輸送で起こりうるもので、商品ページにも記載しています。商品本体に問題があれば写真をお送りください。

---

## 8. 商品の破損・不良（こちらに非がある）

```
您好，非常抱歉造成您的困擾。
已確認商品狀況，我們會立即為您處理，請問您希望：
① 全額退款
② 重新寄送一件新品
兩種方式都不需要您退回商品，請告訴我們您的選擇 🙏
再次為此向您致歉。
```
> 訳: ご迷惑をおかけして申し訳ありません。全額返金か再送をお選びください。返品は不要です。
>
> ※ 非があるときは即座に全面対応する。渋ると評価で倍返しになる。
> ※ **送る前に必ずオーナーの確認を取ること。**

---

## 9. 返品したいと言われた

```
您好，了解您的需求。
由於本賣場商品由日本寄出，國際退貨的運費通常會高於商品金額，
因此我們建議以下方式，商品不需退回：
・部分退款 {金額} 元
若您仍希望退貨，我們也會依照蝦皮的退貨流程處理，請您告知 🙏
```
> 訳: 越境の返送料は商品代を上回ることが多いので、返品不要の一部返金をご提案します。ご希望なら通常の返品手続きも行います。

---

## 10. 値引き交渉

```
您好，感謝您的詢問！
目前的售價已經是我們能提供的優惠價格，商品由日本直送，
運費與關稅都由我們負擔一部分，所以價格上比較難再調整 🙏
不過我們不定期會發放優惠券，歡迎追蹤我們的賣場！
```
> 訳: すでに優遇価格で、日本直送の送料も一部負担しているため値引きは難しいです。クーポンを出すことがあるのでフォローしてください。
>
> ※ 値下げ下限を値付け担当に確認してから答える。

---

## 11. 関税の質問

```
您好，關於關稅：
進口稅費依各國海關規定與商品金額而定，實際是否課稅由海關認定，
若產生稅費需由收件人負擔，這點還請您了解 🙏
```
> ※ 免税枠の金額を断定しない。制度は変わるうえ、税関の判断次第。

```
若有任何需要協助的地方，請隨時與我們聯繫 🙏
```
> ※ 言い訳をしない。反論しない。読んでいるのは次の買い手。
